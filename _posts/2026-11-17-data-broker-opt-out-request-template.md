When a people-search site gives you a confirmation number, save it next to the URL of your listing. If a second listing appears or the original comes back, that pair gives you something concrete to ask the broker about. Here’s an opt-out request you can use in a privacy form or email.

## Before you send the request

Find the broker’s official opt-out form or privacy contact. Look for **Opt Out**, **Your Privacy Choices**, **Do Not Sell or Share**, or **Remove My Information** on its own site. Use the route it provides for removing a listing. If the form asks for a profile, give the exact URL and the name shown on the record. Save a separate URL for each duplicate. [FTC guide to people-search sites and opt-outs](https://consumer.ftc.gov/articles/what-know-about-people-search-sites-sell-your-information)

For verification, start with the listing URL and the matching details the form asks for. If the broker asks for more, check its privacy policy and ask which fields it needs and whether it offers another way to verify. Use its official submission channel for any requested documents. ## Copy this data broker opt-out request

**Subject — Opt-out and removal request for my listing**

> Hello, I’m requesting removal of my personal information from the public listing at [exact listing URL]. The name on the listing is [name as shown].
>
> Please suppress this listing from public results and stop selling or sharing my personal information to the extent your opt-out process covers it. If you offer deletion, please also delete the personal information associated with this listing where applicable.
>
> If you need to verify the request, please tell me the minimum information you need and how to submit it. Please confirm which URL or record was processed, what action you took, and whether any data is being retained to honor the opt-out.

If the broker has separate controls for sale or sharing, public listing removal and deletion, submit the applicable requests through those controls. Keep the date and confirmation number for each. An unsubscribe link handles marketing emails. Use the privacy process for the data itself.

## Follow up with the URL and confirmation number

After the stated processing window, check the original URL in a signed-out browser. Search the broker’s site for your own record again to catch duplicates. You may see the old result on Google even after the public listing goes away. [How to check a stale Google result]({% post_url 2026-11-17-remove-home-address-from-google %})

If the live listing still shows your information, reply through the official request thread or form.

> I submitted request [number] on [date] for [listing URL]. On [date], that URL still showed my [name and phone number, home address, or other field]. Please confirm whether the request applied to this listing and what I need to do next.

Suppose you received a confirmation for profile A and found a second profile with a different URL. Keep the confirmation with profile A and check the broker’s instructions for the second listing. That gives you a way to tell which request changed which page.

California residents can also submit one deletion request to registered brokers through the state. If you’re in Canada, check the broker’s process and the Canadian privacy rules that apply to the organization.
